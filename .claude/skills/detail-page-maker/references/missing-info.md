# 정보·에셋이 없을 때

**화면(고객이 보는 곳)에는 `[확인 필요]`, 빈 사진 상자, "준비 중", 자리표시 문구를 절대 넣지 않는다.** 허접해 보이는 가장 큰 원인이다.

1. 시작할 때 한 번만 묻는다(clarify 한 번에 묶어서): 상품명, 무엇을 해 주는지, 구성·사양, 가격, 실제로 있는 후기·수치·인증, 에셋 폴더 위치, 참고 URL. 사용자가 "알아서"라고 하면 묻지 않고 진행.
2. 모르는 값은 그 요소를 통째로 뺀다: 가격이 없으면 가격 박스를 빼고, 후기가 없으면 후기 섹션을 뺀다. 섹션이 비면 앞뒤 섹션을 늘려 길이를 맞춘다.
3. 에셋이 없는 자리는 (a) 컴포넌트 그래픽(번호 배지·비교표·체크리스트·아이콘 카드·성분 칩·큰 숫자)으로 대체, (b) 참고 URL의 에셋(사용 허락 확인 후), (c) 그래도 없으면 그 섹션을 뺀다.
4. 뺀 것·모르는 값·추정한 것은 `open-items.md`(고객에게 안 보이는 파일)에 모은다: 항목, 왜 뺐는지, 채우려면 필요한 것.
5. 사용자가 나중에 값을 주면 해당 섹션만 고쳐 다음 버전(v02)으로 낸다.
6. 만들지 않는 것: 받은 정보에 없는 후기·별점·판매량·인증·수상·숫자, 지어낸 마감·남은 수량. 마감은 실제 날짜를 받았을 때만 그대로.

# 참고 페이지가 없을 때 기본 순서

| # | 섹션 | 역할 | 손님 속 질문 |
|---|---|---|---|
| 1 | 첫 화면 | 멈추게 | 이거 나한테 뭐가 좋아? |
| 2 | 이런 적 있죠 | 문제 | 내 얘기인가? |
| 3 | 그래서 만들었어요 | 해결 | 뭐가 어떻게 해결돼? |
| 4 | 결과 먼저 | 증거 | 진짜야? 보여 줘 |
| 5 | 구성 | 구성 | 정확히 뭘 받아? |
| 6 | 이렇게 써요 | 사용법 | 나도 할 수 있어? |
| 7 | 가격·받는 법 | 가격 | 얼마고 어떻게 받아? |
| 8 | 자주 묻는 질문 | 안심 | 혹시 ~면? |
| 9 | 마지막 버튼 | 행동 | 지금 뭘 누르면 돼? |

- 증거(4) 칸은 받은 정보 안의 실제 결과·수치·사진만 쓴다. 없으면 섹션을 빼고 `[확인 필요: 실제 결과나 사진]`을 점검표에 적는다.
- 후기 칸은 실제 후기를 받았을 때만 만든다.

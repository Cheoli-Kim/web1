# 이미지 만들기 (에셋이 부족할 때)

**내장 이미지 생성 툴이 있을 때만, 섹션에 필요한데 사진이 없는 연출컷만** 만든다. 개수 목표는 없다. 섹션을 짠 뒤 '이 자리에 쓸 사진이 없다'인 칸만 채우고, 있는 사진으로 되면 만들지 않는다. 같은 컨셉을 반복해 만들지 않는다.

## 어떤 도구를 쓰나 (있는 것 순서대로)

1. **ChatGPT에 이 스킬을 연결해 쓰는 경우:** ChatGPT에 들어 있는 내장 이미지 생성 툴(image_gen)을 그대로 쓴다. 제품 컷이 있으면 참고 이미지로 붙여서 "이 제품을 그대로 두고 배경·구도만 바꿔" 로 요청한다.
2. **Codex CLI가 있는 경우(클로드 코드 등):** `codex exec --skip-git-repo-check -s workspace-write -c model_reasoning_effort=low -- "Call the built-in image_gen tool right away (do not read any skill files): <프롬프트>. Then cp the generated file to ./<이름>.png. Do nothing else." < /dev/null` 를 컷마다 병렬(4개씩)로 돌린다. ChatGPT 요금제로 청구되고 한 장에 약 30~40초.
3. 둘 다 없으면 사용자 사진만 쓰고 모자란 자리는 컴포넌트 그래픽(칩·표·큰 숫자)으로 채운다. 지어낸 사진을 억지로 만들지 않는다.

## 컨셉 예시 (필요한 것만 고른다)

히어로(제품 단독 · 대각 구도) · 물/재료 튀는 컷 · 질감 매크로 · 사용 장면(얼굴은 일부만 · 눈 안 보이게) · 재료 플랫레이 · 세트 구성 · 단상(좌대) 연출 · 야간·무드 컷 · 손에 든 컷 · 패턴 배경(풀블리드용) · 비교·스와치 컷 · 라이프스타일 공간

## 프롬프트 규칙

- 한 장에 한 장면. 비율을 적는다(세로 4:5 / 정사각).
- **"no text no logos no letters"** 를 항상 쓴다. 이미지 안의 글자는 깨진다. 브랜드명·문구는 HTML 텍스트로 올린다.
- 라벨은 비워 둔다("blank label"). 실제 브랜드·실존 인물·유명 캐릭터 금지.
- 색 팔레트를 3색으로 고정해 모든 컷에 같은 단어를 넣는다(예: peach, cream, deep plum).
- 사람이 나오면 얼굴 일부만. 눈이 안 보이는 구도.
- 생성물은 가상임을 기록한다: `assets/README.md` 에 "AI 생성 이미지 · 실제 제품 아님(시연용)" 한 줄. 실제 판매 상품이면 생성 사진을 제품 실물처럼 쓰지 않는다(실물 사진은 사용자가 준 것만).

## 사용

- 큰 사진은 풀블리드 섹션 배경이나 섹션 사이 띠(구분 이미지)로 쓴다. 한 이미지를 두 번 쓰지 않는다.
- 어두운 사진 위 글자는 대비 4.5:1 이상 확보(반투명 면 깔기).

# 카피라이팅 — 레퍼런스를 따라 쓴다 (최우선 원칙)

**카피는 창작하지 않는다. 잘 팔리는 레퍼런스 페이지를 따라 쓴다.** 직접 지은 문장은 시적·추상적으로 흘러 후지다(실패 사례 있음).

## 0. 따라 쓰는 절차
1. 같은 카테고리 상위 판매 상세 2~3개를 `fetch_reference.py` 로 수집하고, 이미지 조각을 **전부 눈으로 읽어** 섹션별 제목·본문·수치 문구를 그대로 `research.md` 에 옮겨 적는다(섹션 순서 포함).
2. 우리 상품 정보(`product-info.md`)로 **문장 뼈대를 그대로 두고 단어만 치환**한다: 상품명·성분·수치·대상·조건. 문장 길이·어미·숫자 위치·제목 형태는 레퍼런스와 같게 유지한다.
3. 레퍼런스에 있는 섹션은 빠짐없이 우리 쪽에도 둔다. 우리에게 없는 정보(수치·인증)만 그 칸을 '시연용 가상 데이터' 또는 삭제로 처리한다.
4. 레퍼런스의 **고유 상표·제품명·로고·원본 이미지**만 쓰지 않는다. 그 외 문장 형태는 따라 한다.
5. 따라 쓸 수 없는 칸에 한해서만 아래 2·3절 규칙으로 직접 쓴다.
6. 공개(게시·판매)용이면 레퍼런스 문장을 그대로 복사하지 말고 같은 구조로 단어를 충분히 바꾼다. 내부 시연·연습용은 사용자가 허용하면 그대로 옮겨도 된다. 실제 시험 수치·인증은 우리 상품 것이 아니면 절대 그대로 쓰지 않는다(공개용).


카피가 후지게 나오는 원인은 둘이다. ① 쓸 재료(차별점·원리·증거)가 없어서 같은 말을 반복한다 ② 참고 페이지의 구조만 보고 **글쓰기 기술**은 안 뜯었다.

## 0. 재료 점검 (쓰기 전)

상품 정보에 아래 5가지가 있는지 본다: 고객의 고민 · 차별점 3개 · 원리·성분 · 증거(수치·사용 테스트) · 사용 장면. **2개 이상 비어 있으면 한 번만 묻는다**(clarify 한 번에 묶어서). 대답이 없으면 비어 있는 칸은 섹션을 빼고 그 자리에 다른 칸을 늘린다. 같은 말을 돌려 쓰며 채우지 않는다.

## 1. 참고 카피 부검 (문장은 가져오지 않고 기술만)

참고 페이지의 제목·문장을 섹션마다 읽고 아래 표를 `research.md`에 쓴다.

| 섹션 | 원문 제목의 형태 | 쓰인 기술 | 우리 상품에 옮기면 |
|---|---|---|---|
형태 예: `[감각 이미지] + [약속]` / `[숫자] + [비교 대상]` / `[고객 상황] + [반전]` / 조어(브랜드만의 이름) / 짧은 단언 + 이유 한 줄

## 2. 팔리는 카피의 모양 (실제 잘 팔리는 페이지에서 확인한 것)

잘 팔리는 페이지 제목은 **평이하고 직설적**이다. 시적이지 않다.

| 실제 쓰이는 모양 | 예 (형태만 · 문장 복사 금지) |
|---|---|
| **이름 붙인 효과** (조어 + 숫자) | "3초 ○○ 효과" — 효과에 이름이 있어 기억되고 광고·후기에서 반복된다 |
| **숫자를 제목 크기로** | "단 1회 3초 사용이면 충분한 효과" · "수분 +8.93%" 큰 숫자 카드 (조건은 작은 글씨로) |
| **원리·구조를 이름으로** | "초저분자 스마트 캡슐" 처럼 기술에 이름을 붙이고 일반 제품과 그림으로 비교 |
| **평이한 약속** | "더 빠르게, 더 깊은 곳까지" — 누구나 한 번에 이해하는 말 |
| **한 섹션 한 혜택** | 제목에 혜택 하나, 아래에 근거(수치·그림) 하나 |
| **비교는 그림·표로** | 일반 제품 vs 우리 제품을 같은 칸에 놓기 |

## 3. 쓰는 규칙

- **시적 표현 금지.** 비유·대구·감성 문장("촉촉한 기분 말고 차오른 수분감", "바른 티는 없고 물기만 남은 얼굴") 쓰지 않는다. 읽는 순간 '그래서 나한테 뭐가 좋은데'가 안 보이면 버린다.
- **제목 = 혜택 또는 이름 붙인 효과 + 숫자/시간.** 숫자는 받은 정보(또는 시연용 가상 데이터)만, 대상·조건을 작게 붙인다.
- **고객이 실제로 쓰는 말.** 리뷰·검색어에서 나온 단어(당김·끈적임·밀림·흡수)를 그대로 쓴다.
- **같은 약속을 두 번 넘게 쓰지 않는다.** 섹션마다 다른 혜택.
- **'~예요' 정의문으로 제목을 쓰지 않는다.**
- **차별점·효과에 이름을 붙인다.**
- **걱정은 먼저 답한다**(Q&A 칸). 단 질문도 고객 말투 그대로.
- 제목은 8~16자 2줄, 둘째 줄이 핵심.

## 3. 검수 (HTML 만든 뒤)

화면 텍스트 전체를 뽑아 ① 같은 구절이 3번 이상 나오는지 ② 섹션 제목만 이어 읽어도 흐름(고민→약속→이유→증거→사용→걱정→행동)이 이어지는지 ③ 제목 중 '정의문'(~예요/~이에요)이 3개를 넘는지, ④ 비유·감성 문장이 있는지 본다(있으면 평이한 혜택 문장으로 바꾼다). 걸리면 고친다.

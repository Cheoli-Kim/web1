# 상세페이지 글꼴·행간 규칙 (480px 기준으로 디자인, 내보낼 때 폭에 맞춰 확대)

상세페이지는 폰에서 엄지로 빠르게 내리며 읽는다. 읽는 글이 아니라 훑는 글이다.

| 요소 | 크기(px, 480 기준) | 행간 | 자간 | 굵기 |
|---|---|---|---|---|
| 첫 화면 큰 제목 | 36~40 | 1.2~1.25 | -0.04em | 800~900 |
| 섹션 제목 | 28~32 | 1.3 | -0.03em | 800~900 |
| 소제목·카드 제목 | 18~20 | 1.4 | -0.02em | 700~800 |
| 본문·리드 | 16~18 | 1.6~1.7 | -0.01em | 400~500 |
| 카드 안 설명 | 14~15 | 1.5 | 0 | 400 |
| 각주·표시 사항 | 12~13 (이보다 작게 금지) | 1.5 | 0 | 400 |
| 큰 숫자 강조 | 56~72 | 1.0 | -0.04em | 900 |

- 글꼴: `"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`. 외부 글꼴 주소 금지(오프라인·검수 때 깨짐). 이미지로 내보내면 글꼴은 그림에 구워져서 플랫폼이 글꼴을 못 바꾼다.
- `word-break: keep-all` 필수(한글 단어 중간 줄바꿈 금지), 제목에는 `text-wrap: balance`.
- 한 줄 글자 수: 제목 12~16자, 본문 20~26자 안팎. 길면 `<br>`로 의미 단위에서 끊는다.
- 본문은 한 덩어리 3줄 이하. 4줄 넘으면 칩·표·체크리스트로 쪼갠다.
- 가운데 정렬은 짧은 제목·한두 줄 문장만. 3줄 이상 설명·목록은 왼쪽 정렬.
- 굵기는 한 화면에 2종류까지(제목 900 + 본문 400). 강조는 굵기보다 색·형광 배경(`em`)·칩으로.
- 색 대비: 본문 글자는 배경 대비 4.5:1 이상. 노란 배경 위 글자는 진한 남색·검정만.
- 여백: 섹션 위아래 56~72, 좌우 24. 카드 사이 12, 카드 안 18~24. 빽빽한 것보다 숨 쉬는 쪽이 비싸 보인다.
- 이미지 내보내기 폭이 860이면 위 크기가 ×1.79로 커진다. 480에서 15px 본문 = 860에서 약 27px.

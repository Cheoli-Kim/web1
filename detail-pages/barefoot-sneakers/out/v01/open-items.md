# 채우면 좋아지는 것 (고객에게 안 보이는 파일)

| 항목 | 왜 뺐나 | 채우려면 |
|---|---|---|
| 제품 사진 (정면·측면·밑창 접힘·착용컷) | 사진을 받지 못함. 지금은 SVG 그림으로 대체 | `assets/`에 사진 넣기 → 첫 화면·POINT 3에 교체 |
| 상품명·브랜드 | 정보 없음. "발벗 스니커즈"로 임시 표기 | 실제 상품명 |
| 가격·혜택 | 정보 없음 → 가격 박스, 하단 바 가격 뺌 | 판매가, 실제 기간이 있는 할인 |
| 사이즈표 (mm·발볼) | 정보 없음 → 재는 법만 안내 | 사이즈별 발길이·발볼 |
| 밑창 두께·무게·소재 | 정보 없음 → 숫자 카드 뺌 | 실측값 (큰 숫자 섹션 추가 가능) |
| 실제 후기·별점 | 없음 → 후기 섹션 뺌 | 실제 구매 후기 |
| 상품정보 고시 (제조국·제조사·소재·A/S) | 없음 → 하단 표 뺌 | 판매처 고시 항목 |

| 참고 상세페이지 | 국내 판매 페이지를 열어 볼 수 없었음 | 잘 팔리는 페이지 링크 주면 구조를 다시 맞춤 |
